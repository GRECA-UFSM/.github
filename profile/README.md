# GRECA-UFSM

GRECA-UFSM is a research group at the Federal University of Santa Maria (UFSM), Brazil, dedicated to advanced research in computer networks, cybersecurity, network management, programmable data planes, and AI for networked systems.

Our repositories cover open research artifacts, reproducible experimental workflows, academic prototypes, datasets, and companion code for scientific publications. We focus on technically grounded and experimentally validated work in areas such as P4 programmable networks, eBPF/XDP, in-network telemetry, observability, traffic analysis, intrusion detection, network automation, and applied machine learning for security and management.

## Research Focus

Our main research areas include:

- Programmable Data Planes (P4, SmartNICs, in-network processing)
- eBPF/XDP and Linux-based packet processing
- Network Telemetry and Observability
- Network Security and Intrusion Detection Systems
- Traffic Analysis, Flow Characterization, and Encrypted Traffic Analysis
- Software-Defined Networking (SDN) and Network Automation
- AI and Machine Learning for Network Management and Cybersecurity
- Synthetic Network Data and Reproducible Network Experimentation
